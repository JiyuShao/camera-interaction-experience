# Third-party assets

## Sleeping Baby

“Sleeping Baby” by [Syral86](https://sketchfab.com/Syral86), sourced from [Sketchfab](https://sketchfab.com/3d-models/sleeping-baby-f64d9f687a2e458883d72489adfa5fba), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The model is modified and optimized into sampled particle-position data for this local experience.

## Animal Crossing leaf

The leaf silhouette is based on [Animal Crossing Leaf.svg](https://commons.wikimedia.org/wiki/File:Animal_Crossing_Leaf.svg), an SVG redraw of Nintendo's official favicon. Wikimedia Commons marks the simple logo geometry as public domain and notes that it may remain subject to trademark restrictions. This project adds original vein details and uses the asset only in the user-requested local experience.

## MediaPipe Hand Landmarker

Hand tracking uses Google MediaPipe `@mediapipe/tasks-vision` 1.0.1 and the official Hand Landmarker full model. Both are licensed under the [Apache License 2.0](./licenses/Apache-2.0.txt). The model runs locally in a Web Worker; camera frames are not transmitted by this project.

- [MediaPipe Hand Landmarker Web guide](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js)
- [Hand tracking model card](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Hand%20Tracking%20(Lite_Full)%20with%20Fairness%20Oct%202021.pdf)
- [MediaPipe source repository](https://github.com/google-ai-edge/mediapipe)

## Background music

“A Little Love” is a user-provided local audio file. Its original licensing information was not included with the file and has not been independently verified; keep its use limited to this private local experience unless the necessary distribution rights are confirmed.
