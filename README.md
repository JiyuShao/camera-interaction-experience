# 星叶初见

一个面向 PC、平板和手机浏览器的满月纪念互动场景：漂浮的叶光会汇聚成横卧熟睡的粒子宝宝，并支持拖动旋转、双指或滚轮缩放、聚合、散开和视角复位。

## 启动

需要 Node.js 22 和 pnpm。

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

## 个性化配置

编辑根目录的 [`experience.config.json`](./experience.config.json)：

- `identity`：宝宝姓名、纪念文案、日期和天数
- `presentation`：网站名称、欢迎页眉题与正文、场景眉题、加载文案和作品介绍
- `creator`：网站制作者的姓名、角色和可选个人链接
- `audio`：背景音乐地址、曲名、音量、循环、自动播放和总开关
- `media`：照片/视频、散开态卡片的大小和透明度，以及自动回忆的旋转与停留速度
- `model`：源模型路径、运行时点位地址、采样数量、旋转/缩放/偏移和署名
- `particles`：叶片/星尘/星芒比例、性能档粒子数和动画时长
- `gestures`：手部推理帧率、通用/比心确认时间、两帧证据门槛、One Euro 连续特征滤波、捏合释放宽限和短暂丢失宽限

替换模型后执行：

```bash
pnpm assets:build
```

脚本会均匀采样 GLB 表面，并生成浏览器使用的 `public/assets/models/sleeping-baby.points`。原始 GLB 位于 `assets/source/`，默认被 Git 忽略，避免把 23MB 的源素材意外提交。

## 质量分级

页面根据设备并发能力、可用内存、视口面积和 DPR 自动选择：

- 高：30,000 粒子，DPR 最高 2
- 中：20,000 粒子，DPR 最高 1.7
- 低：12,000 粒子，DPR 最高 1.35

## 当前范围

当前版本已完成欢迎入口、主场景视觉和可主动开启的摄像头手势：✊ 聚合、🖐 散开、手掌移动旋转、🤏 按住放大当前视野中最靠近画面中心的照片，以及 🫰 韩式单手比心开关自动回忆。手势识别模型与 WASM 均随项目本地提供；摄像头画面只在浏览器本机处理，不上传网络。检测到多个摄像头时，预览顶部可以明确选择设备，选择会保存在当前浏览器中。摄像头拒绝授权或不可用时，鼠标和触控操作仍然完整可用。

背景音乐会在用户点击“开启星光”后播放，以符合浏览器的自动播放限制；右上角的音乐按钮可以随时暂停或恢复。音乐文件、音量、循环、入场播放和总开关均由 `audio` 配置控制。

手势功能需要 `localhost` 或 HTTPS。首次点击“手势”时才会请求摄像头权限并延迟加载约 19MB 的本地 MediaPipe 运行资源。

旋转采用双轴速度控制：手掌停在画面中心附近时保持稳定，向上下左右偏得越远，粒子宝宝就会沿对应方向越快地持续旋转。水平/垂直死区、最大速度和响应曲线可在 `gestures.motion` 中配置。

叶光由密集轮廓叶、清晰主叶片、辅助星尘和少量前景飘叶组成。聚散期间会产生错峰风旋，稳定后主叶片仍会轻微翻面呼吸。叶片比例、大小、前景数量和摆动强度均可在 `particles` 中配置。

## 纪念媒体

将照片或短视频放入 `public/assets/media/`，然后在 `experience.config.json` 的 `media.items` 中按需要添加任意数量：

```json
{
  "kind": "image",
  "src": "/assets/media/full-moon.jpg",
  "thumbnail": "/assets/media/full-moon-thumb.jpg",
  "alt": "宝宝的满月照",
  "caption": "初见满月的这一天",
  "sceneFeatured": true
},
{
  "kind": "video",
  "src": "/assets/media/keepsake.mp4",
  "poster": "/assets/media/keepsake-cover.jpg",
  "alt": "满月纪念短片"
}
```

照片与视频可以混排，数量不限。`thumbnail` 是画廊缩略导航使用的可选轻量图；主场景里的照片卡片直接读取 `src` 原图，并在浏览器内缩放到最长边 1024 像素，兼顾清晰度与显存占用。视频需提供 `poster` 或 `thumbnail` 才会进入主场景。宝宝态不显示媒体，进入星光态后会根据素材总数重新计算三维坐标，让全部可预览素材均匀分散在具有宽度、高度和纵深的空间内部；它们不是固定平面上的一组点。卡片是叶光坐标系中的真实 3D 平面，会随整体旋转产生位置与近大远小的变化，同时每张卡片会逐帧独立朝向摄像头，避免旋转后只剩侧面。`media.sceneCards` 可配置大小范围和透明度。空数组会显示精简的待添加状态。主场景中点击粒子宝宝或点击“纪念”按钮可打开画廊。

🤏 的动作是让拇指和食指指尖贴近，同时中指、无名指和小指保持张开，并稳定保持约 0.16 秒。识别会同时使用屏幕坐标、三维世界坐标和连续特征评分；不够像捏合或比心的中间姿态会留在“不确定区”，不会被强行触发。星光态开启手势后，画面中央会出现低干扰瞄准圈；照片的可见边框进入瞄准区并稳定约 0.16 秒后，会先以金色圆角描边和轻微放大给出预选反馈。捏合到 100% 时锁定这张候选，只有几乎同样居中时才比较摄像机距离，然后平滑飞到屏幕中央并放大到约屏高 56%；旋转途中不会跳到另一张。松开手指即回到原位，不会进入画廊。

🫰 采用韩式单手比心：拇指与食指靠近、横向顺序形成交叉并同时指向手掌上侧、其余三指收拢时，交叉方向本身就是强证据，不要求摄像头每帧都捕捉到两段指骨精确相交，也不再强制要求食指深度稳定领先；若摄像头能可靠看到食指更靠前，这仍会作为辅助证据。比心需要保持约 0.26 秒，并满足至少两帧连续证据；One Euro 滤波、互斥评分和进入/退出迟滞会吸收手指深度与距离的轻微抖动。摄像头预览会显示比心保持进度；第一次比心会自动进入星光态，让叶光缓慢旋转，并依次聚焦所有纪念媒体；再次比心会停止自动回忆并恢复手动操作。底部的“自动 / 停止”按钮提供同样的切换能力，也会明确显示当前状态，因此不依赖摄像头也能使用自动回忆。自动旋转速度和每张照片的聚焦/间隔时长可在 `media.autoTour` 中调整。
